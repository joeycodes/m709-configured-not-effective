### (a) the forward chain as committed

        chain forward {
          type filter hook forward priority 0; policy drop;
          ct state established,related counter accept
          ct state invalid counter drop
          ip saddr 10.103.0.0/16 ip daddr 10.101.0.0/16 counter log prefix "fwd-t2t0-drop: " drop
          ip saddr @allowed_v4 ct state new log prefix "fwd-accept: " counter accept
          counter log prefix "fwd-drop: " drop
        }

### note: established and related packets are accepted by the first rule and invalid ones dropped by the second, so the accept rule sees only first packets; ct state new makes that explicit, and no packet in another state falls through to the final drop (untracked does not occur: no notrack). Log level defaults to warn, which the DCR collects.
