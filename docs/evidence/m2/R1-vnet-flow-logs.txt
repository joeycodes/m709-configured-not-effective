On 2026-10-20 the same configuration produced none of the data side, while the management side (NWTA DCR and DCE) worked. Either may explain it, or neither: one run each, so this is a candidate cause, not a shown one. What the two runs do show is that the same, correct configuration can be effective on one build and not on another, and that nothing in Terraform, the plan checks or the flow-log resource reports the difference; only the data does. The detection side therefore needs its own check that rows arrive (W8). Topology (FlowType) remains open.
